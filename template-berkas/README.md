# Paket Template Berkas IJOP 2026 (Kota Samarinda)

Template dokumen Microsoft Word (`.docx`) di folder ini disusun berdasarkan [Panduan_Legalitas_IJOP_2026_Samarinda.pptx](../Panduan_Legalitas_IJOP_2026_Samarinda.pptx) dan acuan administrasi Kementerian Agama (PD Pontren / SITREN / KUA).

> **Catatan pengisian:** Ganti seluruh teks di dalam tanda kurung siku `[...]` dengan data lembaga Anda, hapus kotak petunjuk (jika ada) sebelum dicetak, dan bubuhkan tanda tangan, meterai Rp10.000 (pada surat pernyataan), serta stempel lembaga/yayasan.
